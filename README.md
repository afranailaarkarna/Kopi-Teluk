# ☕ Kopi Teluk Kendari – Landing Page

**Kopi Teluk Kendari** merupakan sebuah website landing page sederhana yang memperkenalkan kedai kopi lokal dengan konsep kopi khas Sulawesi Tenggara.

Website ini dibuat untuk menampilkan informasi mengenai menu minuman dan makanan, alamat kedai, jam operasional, serta kontak WhatsApp untuk pemesanan.

## ✨ Fitur Website

- **Halaman Utama:** Menampilkan informasi singkat dan pengenalan Kopi Teluk.
- **Menu Andalan:** Menampilkan daftar menu beserta deskripsi dan harga.
- **Informasi Kontak:** Menampilkan alamat, jam buka, dan nomor WhatsApp.
- **Navigasi:** Memudahkan pengunjung berpindah ke bagian menu dan kontak.
- **Footer:** Menampilkan informasi hak cipta website.

## 🛠️ Teknologi yang Digunakan

- HTML – Membuat struktur halaman website.
- CSS – Mengatur tampilan dan desain website.
- JavaScript – Menambahkan fungsi interaktif pada website.
